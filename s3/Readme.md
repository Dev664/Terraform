Important Notes
Resource Names: S3 bucket names must be globally unique across AWS.
AWS Region: Always verify that you are working in the intended AWS region.
Cost Awareness: Monitor your AWS usage and charges, even when using the Free Tier.
Resource Cleanup: Always destroy or delete resources after completing your practice to avoid unnecessary charges.

1. Setup the teraform first in your local system
2. create the main.tf 
3. Run From your Terraform project directory:

```
terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
```
